# MiyooMiniFlip

1. Take out sd card and format to FAT32 (NOT EXFAT) via rufus win 
2. Install [Onion OS](https://github.com/OnionUI/Onion/releases/tag/latest) (4.4.0) , extract files onto flashed sd card and eject
3. Fresh setup Onion OS (go through complete cycle) , Shut down and take out sd card
4. move roms to sd card
