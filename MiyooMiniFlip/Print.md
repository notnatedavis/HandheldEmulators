# Print (guide)

*everything you need*
- approx charge `~ 2h 30min`
    - DONT overcharge (ruins battery)
- `red dot` = this side up
- *to save* :
    - `menu` + `select`
    - open `Save States`
    - set `State Slot` # (dont override)
    - `Save State`
- *to load save* :
    - `menu` + `select`
    - open `Save States`
    - select which `State Slot`
    - `Load State`

--- 

*important keybinds*
- `menu` + `select` opens RetroArch menu
- `menu` + `start` expands scale
- holding `R2` fast forwards
- `menu` + `R2` saves current state to slot
