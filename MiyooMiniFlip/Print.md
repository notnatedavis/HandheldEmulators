# Print (guide)

*everything you need*
- approx charge `~ 2h 30min`
    - DONT overcharge (ruins battery)
- `red dot` = this side up

*to save* : (do both to be extra safe)
  1. Save State (.state)
    - `menu` + `select`
    - open `Save States`
    - set `State Slot` # to auto
      - overwrites on 0, manual selection broken?
    - `Save State`
  2. Save File (.srm)
    - open in-game menu -> save
    - automatically saves `.srm` to core folder

*to load save* : (either works, .srm > .state)
  1. Load State
    - `menu` + `select`
    - open `Save States`
    - select which `State Slot` # (default 0)
    - `Load State`
  2. Load Save
    - load open game via main menu
    - save file should be visible after intro

--- 

*important keybinds*
- `menu` + `select` opens RetroArch menu
- `menu` + `start` expands scale
- holding `R2` fast forwards
- `menu` + `R2` saves current state to slot
